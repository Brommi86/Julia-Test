SCHMÜCKER + SPS HOMEPAGE-DEMO V2

Start: index.html
SPS: sps.html

Wichtig: index.html und sps.html müssen im gleichen Ordner bleiben. Das Imagevideo liegt unter assets/schmuecker-imagevideo.mp4.

Die Texte lassen sich unten rechts über „Texte bearbeiten“ direkt im Browser ändern und mit „Speichern“ lokal im Browser speichern. Das ist nur eine visuelle Konzept-Demo und kein CMS.

Die Schmücker-Startseite nutzt das hochgeladene Imagevideo im Hero-Bereich. Die Bilder werden in dieser Demo direkt von den aktuell öffentlich eingebundenen Schmücker-/SPS-Webseiten geladen.
